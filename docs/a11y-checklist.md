# Accessibility walkthrough

Use this checklist before a submission attempt:

- [ ] Login and sign-up can be completed with keyboard only.
- [ ] Focus remains visible on buttons, links, inputs and choice cards.
- [ ] The wizard stepper can be navigated without a mouse.
- [ ] Every form field has a visible label and useful error message.
- [ ] Status, save and RSVP messages use `role="status"` or `aria-live`.
- [ ] The public RSVP flow works at 200% zoom and on a 320px viewport.
- [ ] Information is not communicated by color alone; status chips include text.
- [ ] The check-in route has a manual entry fallback when camera access is unavailable.
- [ ] Print report content remains readable without the application chrome.
- [ ] Test with `prefers-reduced-motion: reduce` enabled.
